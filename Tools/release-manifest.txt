# The bundled interpreter, staged by Tools/build_runtime.py rather than
# copied from the checkout: CPython's official embeddable package for
# Windows plus the four packages in requirements.txt, installed into
# Runtime/Lib/site-packages. It is what makes a release self-contained --
# no Python to install, no pip, no internet during setup. Not listed as
# individual files because there are some thirty thousand of them; the
# builder verifies it instead by running the staged interpreter and
